autocannon -m GET -c 20 -d 1 -p 2 -w 2 "http://localhost:3000/simple"

autocannon is used to send the request to a API
it is used to test the scalability of the API

-w -> how many worker is from client side
-c -> how many tcp connection we made to server
-p -> how many request we can send at the same time
-d -> duration it will test the API ..here it will test for 1ms
